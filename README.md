# LLM-Assisted-Web-Measurements-Artifacts

This repository contains the prompts, code, generated datasets, and LLM results presented in our paper ‘LLM-Assisted Web Measurements’.

The code and dataset used for the experiments carried out in section 6 is available at: https://govcookies.github.io/ and https://github.com/uw-ictd/GovHTTPS-Data. In particular, we downloaded and executed the code from https://bitbucket.org/srdjanmatic/websci_govcookies/src/master/ over these datasets: https://govcookies.github.io/, https://github.com/uw-ictd/GovHTTPS-Data, and our own generated and reconstructed datasets (/datasets/web_measurements/tranco_top_and_bot_50k_governmental_gpt_oss_filtered.csv, /datasets/web_measurements/tranco_top_and_bot_50k_pornographic_gpt_oss_filtered.csv, and /datasets/web_measurements/vallina_reconstructed_dataset.csv). Using the output produced by the tool, we counted the number of websites containing third-party tracking cookies, since the code stores the cookies associated with each visited URL, by checking whether the cookie domains appeared in the Disconnect list. Similarly, since the code also saves the source code of each visited URL, we extracted all `<script>` tags from the body of the HTML documents and checked whether they appeared in the Disconnect list to identify first-party trackers. For each identified first-party tracker, we counted the number of distinct websites in which it appeared.
