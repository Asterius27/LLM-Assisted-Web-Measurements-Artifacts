This repository contains the prompts, generated datasets, and LLM results presented in our paper ‘LLM-Assisted Web Measurements’.

The code and dataset used for the experiments carried out in section 5.1 is available at: https://github.com/ydimova/oauth_project_code, while the code and datasets used for the experiments carried out in section 5.2 is available at: https://govcookies.github.io/ and https://github.com/uw-ictd/GovHTTPS-Data.

In particular, for the experiments presented in Section 5.1, we downloaded the dataset from https://github.com/ydimova/oauth_project_code/tree/master/data. We then filtered it to retain only those websites that belonged to one of the ten most popular categories and asked Gemini to reclassify them using this same set of top 10 categories. Based on the dataset’s results, we computed and visualized (i) the number of websites requesting minimal scope in each category and (ii) the number of websites requesting minimal scope from specific IdPs in each category, according to both Gemini’s and SiteAdvisor’s classifications.

For the experiments presented in Section 5.2, we downloaded and executed the code from https://bitbucket.org/srdjanmatic/websci_govcookies/src/master/ over these three datasets: https://govcookies.github.io/, https://github.com/uw-ictd/GovHTTPS-Data, and our own generated dataset (/llms_results/privacy_analysis_governmental/tranco_bot_100k_and_top_100k_governmental_dataset.csv). Using the output produced by the tool, we counted and plotted the number of websites (for each country) containing third-party tracking cookies, since the code stores the cookies associated with each visited URL, by checking whether the cookie domains appeared in the Disconnect list. Similarly, since the code also saves the source code of each visited URL, we extracted all `<script>` tags from the body of the HTML documents and checked whether they appeared in the Disconnect list to identify first-party trackers. For each identified first-party tracker, we counted the number of distinct websites (for each country) in which it appeared.
